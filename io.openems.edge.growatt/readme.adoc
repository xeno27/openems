= Growatt SPH Hybrid Inverters

Integration of the Growatt SPH series of hybrid inverters (e.g. SPH4600) as a
fully controllable Energy Storage System, including remote control for
Virtual-Power-Plant operation.

== Implemented Natures

Ess (`Growatt.SPH.ESS`):

- ManagedSymmetricEss
- SymmetricEss
- HybridEss
- StartStoppable

Charger (`Growatt.SPH.Charger`), one instance per MPPT port:

- EssDcCharger

Grid-Meter (`Growatt.SPH.Grid-Meter`):

- ElectricityMeter

== Remote control

Two control paths are available; the `Control mode` configuration selects
between them.

=== VPP protocol (recommended)

`Control mode` = `REMOTE_VPP` uses the dedicated Growatt VPP protocol (register
bank 30000-32099, GROWATT VPP COMMUNICATION PROTOCOL OF INVERTER V2.01). It
provides a real remote Set-Point:

|===
|Register |Name |Meaning

|30407
|Remote power control enable
|1 overrides the time-slot schedule and self-consumption

|30408
|Remote power control charging time
|0 = until revoked; written as 0

|30409
|Remote charge and discharge power
|Signed percentage, *positive is charge*, negative is discharge

|30474
|Actual control value
|Read-back of the value the inverter actually applies
|===

These three registers are explicitly *not* stored in non-volatile memory, so
they are written in every Cycle without quantization or throttling. Note the
inverted sign convention: OpenEMS counts positive as discharge, Growatt counts
positive as charge.

The percentage refers to the DC side of the battery. The reference power is the
`BDC rated power` configuration; with the default 0 it is read from the
inverter (register 30026).

`Control authority` (30100) is enabled once, and the watchdog registers
30203/30204 (`EMS failure time`) make the inverter fall back to its own
schedule if OpenEMS stops writing.

The VPP register bank additionally provides much better measurements, which are
preferred automatically when available: AC power (31100), battery power as a
single signed value (31200), *dynamic battery power limits from the BMS*
(31210/31212), SOC/SOH, fault and alarm codes with sub codes.

==== Availability and fallback

The VPP register bank only exists on firmware that implements the protocol. The
Component probes it with register 30000 (equipment type code): it is the first
register of the bank and documented as a single register, so the probe cannot
fail because of a partial read of a multi-register group. The probe gives up
after five consecutive errors and is restarted whenever the Modbus connection
recovers. On a device without VPP support this costs a handful of failed reads
at startup.

The probe requires a plausible equipment type code: some inverters answer a read
on the VPP register bank with zeros instead of rejecting it, and Table 3-1 of
the protocol document has no code zero, so a zero is treated as 'no VPP'.

Note on register 30099 (VPP protocol version): it was only added with protocol
version V2.0, while the control registers 30407-30409 exist since V1.01. Older
firmware can therefore support VPP and still report 0 here - which is why the
probe does not use this register. Beyond that, the protocol document lists it
with a length of 15, which cannot be right - that would reach up to 30113 and
collide with 30100 'Control authority', 30101 'On off command' and 30104
'System time'. The register bank is contiguous, so 30084 'Reserved' covers
30084-30098 and 30099 is a single register. It is read in its own Task, so a
device that rejects the read does not affect the other VPP Tasks.

If `REMOTE_VPP` is configured but the inverter does not answer, the
`VPP_NOT_AVAILABLE` warning is raised and the Component falls back to the
priority and time-slot control described below.

Supported models per the protocol document (Table 3-1) include SPH 3000-6000TL
BL (DTC 3502) and SPH 4000-10000TL3 BH-UP (DTC 3601), i.e. both SPH4600
variants.

=== Priority and time-slot control (legacy)

`Control mode` = `REMOTE` uses the storage registers of the Growatt Inverter
Modbus RTU Protocol_II. The SPH inverters have no register for an absolute power Set-Point. The energy
flow is controlled by the 'Priority Mode' in combination with a power rate in
percent of the nominal battery power:

|===
|Set-Point |Priority Mode |Registers

|negative (charge)
|Battery-First
|1090 charge power rate, 1092 AC-charge, 1102 time-slot enabled

|positive (discharge)
|Grid-First
|1070 discharge power rate, 1082 time-slot enabled

|zero
|Load-First
|1082 and 1102 time-slot disabled
|===

Time-slot 1 of 'Grid-First' (1080-1082) and of 'Battery-First' (1100-1102) is
reserved by this implementation and is set to 00:00-23:59, so that the priority
mode is effective the whole day. Time-slots 2 and 3 stay available for a
schedule that is configured via ShinePhone.

With `Control mode` = `INTERNAL` (the default) OpenEMS never writes a
Set-Point.

==== Protecting the non-volatile memory

Growatt stores these settings in non-volatile memory, which wears out on cyclic
writes. Three mechanisms keep the number of writes low:

- the calculated power rate is quantized (`Power rate step`, default 5 %),
- every value is written through `ChannelUtils.setWriteValueIfNotRead`, i.e.
  only if it differs from the value that was read back from the device,
- a minimum interval between two writes is enforced (`Minimum write interval`,
  default 30 s).

== Modbus

RS485 / Modbus RTU with 9600 baud, 8N1, Unit-ID 1 by default; a Modbus-TCP
gateway works as well. Measurements are Input-Registers (FC4), settings are
Holding-Registers (FC3 to read, FC16 to write). 32-bit values are transmitted
high-word first.

Only one Modbus master is allowed on the RS485 bus - a ShineWiFi/Shine stick
that polls the same bus in parallel causes CRC errors and lost responses.

=== Source of the register addresses

The VPP register bank (30000-32099) is taken from GROWATT VPP COMMUNICATION
PROTOCOL OF INVERTER V2.01 (2024-09-20).

The following core registers are verified in the field (evcc template
`growatt-hybrid`): Input 1, 91, 1009, 1011, 1014, 1021, 1029, 1046, 1054 and
Holding 1092, 1100-1102.

All further addresses are taken from the Growatt Inverter Modbus RTU
Protocol_II (storage section) and should be verified against the protocol
document of the concrete device series before productive use.
